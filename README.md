📅 Automatic Timetable Generator

📌 Project Overview

The **Automatic Timetable Generator** is a web-based application designed to generate academic timetables efficiently. It eliminates manual scheduling conflicts and saves time by automating the timetable creation process.

🚀 Features

* Add and manage subjects, teachers, and classrooms
* Automatically generate clash-free timetables
* User-friendly interface for easy interaction
* Secure login system for administrators
* Database integration for storing records


🛠️ Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Python (Flask)
* Database: SQLite (via Flask-SQLAlchemy)


⚙️ Installation & Setup

 1. Clone the repository

bash
git clone <your-repo-link>
cd TimetableGenerator


2. Create virtual environment (recommended)

bash
python -m venv venv
venv\Scripts\activate


3. Install dependencies

bash
pip install -r requirements.txt

4. Run the application


python app.py


5. Open in browser


http://127.0.0.1:5000

📊 How It Works

1. User enters details (subjects, faculty, time slots)
2. System processes constraints
3. Generates optimized timetable automatically
4. Displays output in a structured format

* Avoids scheduling conflicts

* Easy to use
